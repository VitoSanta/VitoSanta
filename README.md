# Vito Santanelli

AI-focused software engineer building local-first coding agents, evaluation harnesses, and reliable LLM systems.

I work across Rust, Python, and .NET, with an emphasis on local-first AI, reproducible evaluation, deterministic verification, and security boundaries that remain outside model control.

## Current focus

- [**poorAI**](https://github.com/VitoSanta/PoorAI) — a model- and hardware-aware coding agent in Rust for local Ollama deployments. It combines empirical capability probing, context calibration, repository retrieval, typed tools, and deterministic task verification. Available as a public alpha.

## Selected work

- [**Aegis**](https://github.com/VitoSanta/aegis) — deployment-tested AI support system with RAG, durable human-in-the-loop workflows, deterministic multi-tenant authorization, MCP tools, and reproducible evaluation.
- [**pdf-translator**](https://github.com/VitoSanta/pdf-translator) — local Ollama document translator designed to preserve PDF layout and keep documents on-device.
- [**national-identifiers**](https://github.com/VitoSanta/national-identifiers) — cross-runtime TypeScript and .NET validation library covering national tax IDs, VAT numbers, and company identifiers.
- [**FleetOps**](https://github.com/VitoSanta/FleetOps) — cloud-native fleet-management reference architecture built with .NET, Angular, Docker, Kubernetes, and event-driven microservices.

## Engineering principles

- Measure model and system behaviour instead of inferring it from names or marketing claims.
- Treat every optimization as a hypothesis until a reproducible benchmark validates it.
- Keep authorization, workspace boundaries, and verification deterministic and outside model control.
- Record limitations and failed experiments alongside successful results.
